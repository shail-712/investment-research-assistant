# Investment Research Agent

An intelligent, serverless Investment Research Assistant built with AWS SAM and Google's Gemini LLM. The agent provides insights into financial data, latest news, and deep analysis from financial documents using Retrieval-Augmented Generation (RAG).

## Architecture

This project is built using the **AWS Serverless Application Model (SAM)** and runs on Python 3.12. It consists of a central orchestration agent and specialized micro-services:

- **AgentLambda**: The main entry point exposing a `/ask` REST API (POST). It interprets user queries, identifies required tools (market, news, RAG), invokes the necessary child lambdas, builds a context block, and uses the **Gemini 2.5 Flash Lite** model to generate a comprehensive answer.
- **MarketDataLambda**: Fetches real-time market data including price, open/high/low, volume, market cap, and P/E ratio using the `yfinance` library.
- **NewsLambda**: Retrieves the latest news headlines for a specified company using `feedparser`.
- **RetrieverLambda**: A RAG pipeline that searches through financial documents stored in an S3 bucket (`investment-research-kb-shail`). It utilizes `faiss-cpu` for vector similarity search and `pdfplumber` for PDF processing.

## Prerequisites

- AWS CLI installed and configured
- AWS SAM CLI installed
- Python 3.12
- Google Gemini API Key
- An S3 bucket for storing knowledge base documents (e.g., `investment-research-kb-shail`)

## Configuration

The application requires a Gemini API key to function. This key is fetched securely from AWS Systems Manager (SSM) Parameter Store.

Before deploying, ensure you have created a SecureString parameter in SSM:
- Name: `/investment-research/gemini-api-key`
- Value: `<your-gemini-api-key>`

## Deployment

To build and deploy the application for the first time, run the following in your shell:

```bash
sam build
sam deploy --guided
```

For subsequent deployments, you can simply run:

```bash
sam build && sam deploy
```

## Usage

Once deployed, SAM will output the API Gateway Endpoint URL. You can invoke the agent by sending a POST request to the `/ask` endpoint:

```bash
curl -X POST <API_GATEWAY_URL>/ask \
  -H "Content-Type: application/json" \
  -d '{"query": "What is the current stock price and latest news for NVIDIA?"}'
```

The agent will automatically classify the query, extract the company (e.g., NVIDIA / NVDA), gather context from the market data and news lambdas, and return a synthesized response generated by Gemini.

## Local Testing

You can use the provided JSON event files (`event.json`, `news_event.json`, `retriever_event.json`) to test individual lambda functions locally using the SAM CLI:

```bash
sam local invoke AgentLambda -e event.json
```
